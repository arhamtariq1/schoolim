# Incident log

One file per incident: `YYYY-MM-DD-slug.md`.

Open the file **first**, before investigating (`../18-incident-response-and-operations.md` §2).
Timestamp every line. Every S1 and S2 gets a post-incident review within 7 days using the template
in `18` §5 — and every review must produce **at least one automated check**: a test, an alert, a CI
gate, or a database constraint.
